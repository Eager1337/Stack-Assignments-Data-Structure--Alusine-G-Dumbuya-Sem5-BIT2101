## 1. Assignment Overview
This project implements a Python stack-based mathematical expression evaluator. The program reads expressions from `input.txt`, evaluates them using a custom `Stack` class, and writes the results to `output.txt` while preserving the separator structure.

## 2. Files
- `stack_evaluator.py` – complete Python source code.
- `input.txt` – sample input required for testing.
- `output.txt` – output generated by the program.
- `README.md` – setup, structure, assumptions, and limitations.
- `DSCOMP320_Assignment_Report.docx` – hard-copy report.
- `DSCOMP320_Assignment_Report.pdf` – PDF version of the report.
- `requirements.txt` – confirms that no third-party Python packages are required.

## 3. Requirements
- Python 3.9 or newer is recommended.
- No external packages are required.

## 4. How to Run in VS Code
1. Open this folder in Visual Studio Code.
2. Make sure `input.txt` is in the same folder as `stack_evaluator.py`.
3. Open the VS Code terminal.
4. Run:

```text
python stack_evaluator.py
```

On systems where `python` maps to another version, use:

```text
python3 stack_evaluator.py
```

5. The terminal will display a completion message.
6. Open `output.txt` to see the generated results.

## 5. Input File Format
Each mathematical expression is placed on its own line. Expressions may be separated by a line containing a repeated separator such as:

```text
-----
```

Example:

```text
3 + 5 * 2
-----
(8 / 4) + 7 * 2
-----
10 - (2 + 3) * 4
```

## 6. Supported Operations
The evaluator supports:
- Addition: `+`
- Subtraction: `-`
- Multiplication: `*`
- Division: `/`
- Parentheses: `(` and `)`
- Operator precedence: multiplication/division before addition/subtraction
- Decimal numbers

The evaluator is stack-based and does not use Python's `eval()` function.

## 7. Error Handling
The program reports invalid expressions in the output instead of stopping the entire file-processing operation. It checks for:
- Invalid characters
- Unsupported operators
- Missing operands
- Mismatched parentheses
- Division by zero
- Empty expressions

## 8. Assumptions and Limitations
- The assignment requires binary `+`, `-`, `*`, and `/` operators; unary plus/minus is not required.
- Expressions use standard arithmetic precedence.
- The separator is expected to be a repeated punctuation line such as `-----`.
- The program processes one expression per line.
- Division produces a floating-point result when the mathematical result is not an integer.
- No external expression-evaluation library is used.

## 9. Important Note About the Assignment Example
The supplied assignment image appears to show `17` as the output for `(8 / 4) + 7 * 2`. Under the stated standard arithmetic precedence, the correct calculation is:

`(8 / 4) + (7 * 2) = 2 + 14 = 16`

Therefore, this implementation produces `16`, which is the mathematically correct result. This discrepancy should be pointed out to the lecturer if the printed example is intended to be an official expected answer.
